# ASTÉRA — Website Fashion

Website statis multi-halaman untuk latihan UTS Pemrograman Web Dasar.

## Struktur
- `index.html` — Beranda
- `tentang.html` — Tentang brand, nilai, dan tim
- `katalog.html` — Katalog 6 produk dengan pencarian dan filter
- `kontak.html` — Informasi kontak, tabel jam operasional, peta, dan formulir
- `css/style.css` — Seluruh CSS eksternal
- `js/script.js` — Menu mobile, filter katalog, dan umpan balik formulir
- `img/` — Folder untuk gambar lokal (opsional)

## Cara menjalankan
Buka `index.html` di browser atau gunakan ekstensi Live Server di VS Code.

## Catatan penting untuk pengumpulan
ASTÉRA di dalam paket ini ditulis sebagai **brand konsep**. Soal UTS meminta profil usaha/organisasi nyata di sekitar mahasiswa. Pastikan dosen mengizinkan brand konsep, atau ubah nama, profil, alamat, kontak, jam operasional, produk, dan data tim agar sesuai dengan usaha nyata yang dipilih.

Nama produk, harga, tim, alamat, email, dan jam operasional pada template ini adalah contoh dan harus disesuaikan. Formulir hanya demo sisi depan; belum mengirim pesan ke server.

## Sumber gambar
Foto menggunakan URL gambar dari Unsplash (images.unsplash.com). Periksa kembali lisensi dan cantumkan sumber sesuai ketentuan tugas sebelum pengumpulan. Google Fonts: Cormorant Garamond dan DM Sans.
